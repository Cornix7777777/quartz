# Scalar vs Vector

| Scalar                                                       | Vector                                                                                                                                                     |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MAGNITUDE only                                               | BOTH magnitude and direction                                                                                                                               |
| Always positive, can be zero                                 | canNOT be zero, can be negative                                                                                                                            |
| Examples:<br><br>Speed (m/s), <br>Mass, <br>Volume, <br>Time | Examples:<br><br>Velocity (speed + direction)<br>Weight (mas x acceleration due to gravity),<br>Friction (acts on opposite direction of force applied)<br> |

> [!info] Average Acceleration due to Gravity (Earth)
> g = 9.81 $m/s^2$
> For computing purposes: 10 $m/s^2$

## Displacement vs Distance

| Displacement                                                                                                    | Distance                             |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Vector                                                                                                          | Scalar                               |
| Final position - initial position,<br>SHORTEST length between object's start and endpoint + direction of motion | TOTAL length of path object traveled |
| Used to find velocity                                                                                           | Used to find speed                   |
| Symbol: d⃗ (d with arrow)                                                                                       | Symbol: d                            |
![[Pasted image 20261021143821.png]]

> [!info] Note
> - Displacement is always less than or equal to distance
> - If initial position = final position, d⃗ = 0

## Scalar Addition
Literally just addition, ex:
- 6 secs + 3 secs = 9 secs
- 50m + 100m = 150m
- 5kg + 10kg = 15kg

## Vector Addition
Vector addition is done using **Parallelogram law**/**Triangle method**/**Head-To-Tail method**

# Motion
- motion always described in terms of a **reference point** (initial)
- Motion is different for different reference points/the choice of reference point determines an object's relative motion

## Reference point
- place or object used for comparison to determine if something is moving
- often stationary objects (tree, sign, building, etc.)
- often called **origin** and given position value of 0
