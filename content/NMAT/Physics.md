# Scalar vs Vector

| Scalar                                                       | Vector                                                                                                                                                     |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MAGNITUDE only                                               | BOTH magnitude and direction                                                                                                                               |
| Always positive, can be zero                                 | canNOT be zero, can be negative                                                                                                                            |
| Examples:<br><br>Speed (m/s), <br>Mass, <br>Volume, <br>Time | Examples:<br><br>Velocity (speed + direction)<br>Weight (mas x acceleration due to gravity),<br>Friction (acts on opposite direction of force applied)<br> |

> [!info] Average Acceleration due to Gravity (Earth)
> g = 9.81 $m/s^2$
> For computing purposes: 10 $m/s^2$

## Displacement vs Distance

| Displacement                                                                                                    | Distance                             |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Vector                                                                                                          | Scalar                               |
| Final position - initial position,<br>SHORTEST length between object's start and endpoint + direction of motion | TOTAL length of path object traveled |
| Used to find velocity                                                                                           | Used to find speed                   |
| Symbol: d⃗ (d with arrow)                                                                                       | Symbol: d                            |

![[Pasted image 20261021143821.png]]

> [!info] Note
> - Displacement is always less than or equal to distance
> - If initial position = final position, d⃗ = 0

## Scalar Addition
Literally just addition, ex:
- 6 secs + 3 secs = 9 secs
- 50m + 100m = 150m
- 5kg + 10kg = 15kg

# Motion
- motion always described in terms of a **reference point** (initial)
- Motion is different for different reference points/the choice of reference point determines an object's relative motion

## Reference point
- place or object used for comparison to determine if something is moving
- often stationary objects (tree, sign, building, etc.)
- often called **origin** and given position value of 0

## Speed vs Velocity vs Acceleration

| Speed                                | Velocity                                            | Acceleration                                               |
| ------------------------------------ | --------------------------------------------------- | ---------------------------------------------------------- |
| Car is moving at speed of 60 km/h    | Car is moving at speed of 60 km/h in east direction | Car moves at 60 km/h, then after 10 secs, moves at 30 km/h |
| **Distance** travelled per unit time | **Displacement** covered per unit time              | **Change in velocity** over time                           |
| v = d/t                              | v⃗ = d⃗/t                                           | a⃗ = Δv⃗/∆t                                                |

![[Pasted image 20261021151203.png]]

> [!info] Note
> Average speed is NOT always the magnitude of average velocity. Let's say that the overall running speed of a person is five meters per second. We CAN'T conclude that it is also their velocity, provided that the runner ended where they started.

## Instantaneous Velocity/Acceleration
No computation, just understand concept

| Instantaneous Velocity                                                                                                                                                    | Instantaneous Acceleration                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| - Vector quantity describing velocity at **specific instant**<br><br>- 1st derivative of x (position) w/ respect to t (time) given that there is a position function x(t) | 2nd derivative of x (position) w/ respect to t (time) given that there is a position function x(t) <br><br>OR<br><br>1st derivative of velocity function |

### Summary

|       | Displacement (x) vs Time | v vs t                     | a vs t                             |
| ----- | ------------------------ | -------------------------- | ---------------------------------- |
| Slope | Velocity (m/s)           | Acceleration <br>($m/s^2$) | Jerk/jolt or nothing/none of these |
| Area  | Nothing/none of these    | Displacement<br>(m)        | Velocity (m/s)                     |

| Line/slope direction | x vs t                 | v vs t                                  |
| -------------------- | ---------------------- | --------------------------------------- |
| right/upward         | ↑x,<br>v = (+)         | ↑v,<br>a = (+)                          |
| flat                 | x = constant,<br>v = 0 | v = constant (uniform motion),<br>a = 0 |
| Left/backward        | ↓x,<br>v = (-)         | ↓v,<br>a = (-)                          |
