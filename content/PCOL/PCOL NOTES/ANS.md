## A. Nervous System
- Central (Brain, Spinal cord)
- Peripheral (Peripheral nerves)

Stimulus → Sensory/Afferent fibers → BRAIN → motor/efferent fibers → response! 

| Autonomic NS                                 | Somatic NS                                   | Enteric NS               |
| -------------------------------------------- | -------------------------------------------- | ------------------------ |
| INvoluntary movements,<br>**SMOOTH** muscles | Voluntary movements,<br>**SKELETAL** muscles | Intrinsic control of GIT |

> **Myenteric plexus** "Auerbach motility",
> **Submucosal plexus** "Meissner secretions"

> - *Vasoactive intestinal peptide* (VIP): ↓[H+], ↑[$HCO_3^-$]
> - *Gastrin releasing peptide*: ↑Gastrin, ↑[H+]
> - *Enkephalins*: ↓Peristalsis

### 3. Effects of Sympa and Para

|                   | SYMPA                                                                 | PARA                                                                     |
| ----------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------ |
|                   | "adrenergic"<br>Fright, Fight, Flight                                 | "cholinergic"<br>Rest and Digest                                         |
| **EYES**          | *Mydriasis*<br>(Dilation)                                             | *Miosis*<br>(Constriction)                                               |
| **HEART**         | ↑HR <br>(*Tacchy*cardia)                                              | ↓HR <br>(*Brady*cardia)                                                  |
| **LUNGS**         | Broncho*DILATION*                                                     | Broncho*CONSTRICTION*                                                    |
| **GIT**           | ↓Peristalsis                                                          | ↑Peristalsis                                                             |
| **Urinary Track** | Urinary *retention*<br><br>Detrusor: RELAXED<br><br>Sphincter: CLOSED | *Urination*/Micturition<br><br>Detrusor: CONTRACT<br><br>Sphincter: OPEN |
| **PENIS**         | *Ejaculation*<br>"Shoot"                                              | *Erection*<br>"Point"                                                    |
| **Sweat Glands**  | ↑Sweating<br>(*Apocrine*)                                             | ↑Sweating<br>(*Eccrine*)                                                 |
